# Fusion 360 到 MuJoCo 转换简化路线图

**日期**: 2025-09-05  
**状态**: 规划中  
**优先级**: 高  

## 概述

基于已完成的坐标系统修复工作，规划简化的 Fusion 360 到 MuJoCo 转换流程，专注于核心功能实现。

## 当前状态

✅ **已完成**:
- Fusion 360 导出文件格式定义
- 基于导出文件的 MuJoCo XML 构建
- 坐标系统修复（位置计算）
- 扁平化 XML 结构生成

🔄 **进行中**:
- 等待包含旋转数据的导出

## 简化路线图

### 1. Fusion 360 导出文件
- **目标**: 定义完整的导出数据格式
- **已完成**: 基本位置和矩阵数据导出
- **待完成**: 旋转四元数数据导出

### 2. MuJoCo XML 构建
- **目标**: 基于导出数据生成完整的 MuJoCo 模型
- **已完成**: 位置计算和扁平化结构
- **待完成**: 旋转四元数计算和应用

## 核心流程

```
Fusion 360 → JSON导出 → 解析数据 → 生成XML → MuJoCo仿真
```

## 关键技术点

1. **数据格式**: JSON 格式，包含组件信息、位置矩阵、STL 文件
2. **坐标转换**: 行主序矩阵 (3,7,11) 提取位置，厘米转米 (×0.01)
3. **结构生成**: 扁平化结构，所有组件直接位于 worldbody 下
4. **旋转处理**: 待实现四元数计算（等待数据）

## 下一步计划

1. **旋转数据**: 等待 Fusion 360 导出包含旋转四元数的数据
2. **四元数计算**: 实现矩阵到四元数的转换
3. **完整验证**: 验证位置和旋转的准确性
