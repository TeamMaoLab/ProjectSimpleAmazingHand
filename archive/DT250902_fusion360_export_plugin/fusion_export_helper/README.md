# fusion_export_helper

## 当前功能

本插件是一个基于Fusion360的导出工具，能够将当前打开的3D模型导出为多种格式，并生成位置信息数据用于MuJoCo仿真。

### 导出格式支持
- **STL格式**：3D打印标准格式，包含所有组件和实体
- **STEP格式** (.stp)：CAD交换标准格式
- **IGES格式** (.igs)：另一种CAD数据交换格式
- **DXF格式**：2D草图导出格式
- **F3D/F3Z格式**：Fusion360原生格式备份

### 核心功能
1. **智能导出**：自动识别当前打开的Fusion360项目
2. **分层导出**：按组件-实体层次结构导出所有3D对象
3. **位置信息提取**：为每个组件和实体提取精确的3D变换矩阵
4. **JSON数据生成**：创建包含所有对象位置信息的JSON文件，便于MuJoCo使用
5. **批量处理**：支持STL文件的批量导出到统一文件夹
6. **智能命名**：自动处理文件名冲突，支持中英文混合命名

### 数据结构
导出时生成的JSON文件包含：
- 组件名称和类型
- 3D位置坐标 (X, Y, Z)
- 4x4变换矩阵
- 实例化信息
- 父子组件关系

## 中文版本使用指南(maoge)
- 实用程序
- 附加指南
- 脚本和附加模块 
- 左上角搜索框右边有一个"+"号
- 来自设备的脚本或者附加模块
- 把路径指到这个项目你放的位置就行了

使用的时候
- 打开一个你想要导出的项目
- 实用程序>附加指南>把左边的来源"从设备勾上"
- 然后你就能看见 "Fusion 360 Total Exporter"
- 有个播放键，这个播放键点击一下就可以执行本程序了哦
